# 数据库初始化内存问题说明

## 问题描述

在执行 `init_database.py` 时遇到 Doris 数据库服务器内存不足的问题。

**错误信息：**
- 系统可用内存：325-390 MB
- 低水位线：390.46 MB
- 可用内存低于低水位线，无法执行数据库操作

## 问题原因

Doris 数据库服务器（172.20.81.3）的内存配置不足或当前有其他进程占用了大量内存。

## 解决方案

### 方案1：等待内存释放（推荐）

1. **等待 10-15 分钟**，让 Doris 服务器释放内存
2. 然后重新运行初始化脚本：
   ```powershell
   cd backend
   python init_database.py --people 50 --movements 100
   ```

### 方案2：增加 Doris 服务器内存

如果使用 Docker 运行 Doris，可以增加容器的内存限制：

```yaml
services:
  doris:
    deploy:
      resources:
        limits:
          memory: 4G  # 增加到 4GB
```

### 方案3：使用更小的数据量

如果内存仍然不足，可以分批次初始化：

```powershell
# 第一次：只初始化人员数据
python init_database.py --people 10 --movements 0

# 等待几分钟后，再初始化流动记录
# （需要修改脚本，支持只生成流动记录）
```

### 方案4：检查 Doris 服务器状态

检查 Doris 服务器的内存使用情况：

```bash
# 如果可以直接访问服务器
free -h
# 或
docker stats  # 如果使用 Docker
```

## 当前状态

- 数据生成：✅ 成功（已生成人员数据）
- 数据插入：❌ 失败（内存不足）
- 已插入数据：0 条（所有插入操作都因内存不足失败）

## 建议

1. **优先等待内存释放**：这是最简单的方法
2. **检查其他进程**：确认是否有其他进程占用了大量内存
3. **考虑增加服务器内存**：如果经常遇到此问题，建议增加 Doris 服务器的内存配置

## 临时解决方案

如果急需使用系统，可以：
1. 手动通过前端界面导入少量数据
2. 等待 Doris 服务器内存释放后再运行初始化脚本
