# 标签管理模块使用说明

## 功能概述

标签管理模块允许您动态管理人员档案页面的标签体系，支持四级标签结构：
- **一级：分类**（如"基本信息"）
- **二级：子分类**（如"年龄"、"性别"）
- **三级：标签组**（如"年龄段"、"性别分类"）
- **四级：标签项**（如"18-25岁"、"男"）

## 如何隐藏/显示标签管理模块

### 方法一：修改配置文件（推荐）

编辑 `frontend/src/config/tagManagement.js` 文件：

```javascript
// 标签管理模块开关：true=显示，false=隐藏
export const ENABLE_TAG_MANAGEMENT = false  // 改为 false 即可隐藏
```

修改后：
1. 导航栏中的"标签管理"链接会自动隐藏
2. 标签管理路由会自动移除
3. 无法通过URL直接访问标签管理页面

### 方法二：注释路由（不推荐）

如果只是临时隐藏，可以注释掉路由配置，但导航链接仍会显示。

## 使用方法

1. **访问标签管理页面**
   - 在导航栏点击"标签管理"（如果已启用）
   - 或直接访问 `/tag-management`

2. **新增分类**
   - 点击"新增分类"按钮
   - 输入分类名称

3. **新增子分类**
   - 在分类下点击"+ 子分类"按钮
   - 输入子分类名称

4. **新增标签组**
   - 在子分类下点击"+ 标签组"按钮
   - 输入标签组名称

5. **新增标签**
   - 在标签组下点击"+ 标签"按钮
   - 输入标签名称

6. **编辑标签**
   - 直接点击输入框进行编辑
   - 失去焦点时自动保存

7. **删除操作**
   - 点击对应的"删除"按钮
   - 确认后删除（会同时删除下级所有内容）

## 数据存储

- 标签数据存储在浏览器的 `localStorage` 中
- 存储键名：`tag_categories_data`
- 修改后会自动同步到人员档案页面

## 注意事项

1. 删除操作不可恢复，请谨慎操作
2. 标签修改后，人员档案页会自动更新
3. 如果清空浏览器缓存，标签数据会恢复为默认值
4. 四级标签结构在人员档案页会自动转换为三级结构（合并标签组）
